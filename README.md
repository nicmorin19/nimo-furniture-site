# NiMo — Premium Ergonomic Office Furniture

![NiMo Logo](https://img.shields.io/badge/Brand-NiMo-DC2626?style=for-the-badge)

NiMo is a high-end, conversion-focused e-commerce concept for a modern office furniture brand. Designed with an "Apple-like" minimalist aesthetic, the site prioritizes clean grids, generous white space, and high-contrast accessibility using a signature **NiMo Red** accent.

## ✨ Key Features

* **Conversion-First Design:** Optimized for both B2C (Direct Purchase) and B2B (Bulk Quote Requests).
* **Modern Tech Stack:** Built with HTML5, Tailwind CSS, and Vanilla JavaScript for lightning-fast performance.
* **Responsive Layout:** Mobile-first architecture ensuring a premium experience on all devices.
* **Interactive UI:** Custom-coded product image galleries and color swatches.
* **SEO Optimized:** Semantic HTML5 tags and meta-description ready.
