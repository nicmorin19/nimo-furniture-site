## 🏗️ The NiMo Ecosystem

The project has evolved into a comprehensive 5-page professional site:

1.  **Homepage (`index.html`):** Brand introduction and high-level value propositions.
2.  **Product Detail (`product.html`):** Deep-dive into the *Atlas Task Chair*, featuring interactive color selection and high-resolution imagery.
3.  **Services (`services.html`):** Detailed breakdown of 3D Space Planning, Custom Design, and White-Glove Installation.
4.  **About (`about.html`):** The story of NiMo's commitment to ergonomics and sustainable craftsmanship.
5.  **Contact & Quote (`contact.html` / `quote.html`):** Dual-path conversion funnel for general inquiries and detailed B2B project specifications (including file upload support).

---

## ✨ Advanced Features

* **Master Navigation:** A unified header with a "Products" mega-menu and "Active Page" visual indicators.
* **Lead Capture:** A specialized Quote Request system that supports floor plan uploads for corporate clients.
* **Brand Identity:** Strict adherence to the NiMo Red (`#DC2626`) accent system against a high-contrast Slate and White palette.
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing using Tailwind's utility-first grid.
